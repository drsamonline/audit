## The six things a new session must know

1. **#22 is fixed, and the class is gated.** The accept/reject trial measured itself
   (`base64_pays → actual_cost → compress → wav stage → base64_pays`); any valid WAV of
   256 bytes or more died with SIGSEGV. `trial_options()` now switches off every stage
   that gates on `actual_cost()`, and `trial_reentries()` makes a recurrence a test
   failure. Before you add a stage that gates on that trial, read `trial_options()`.
2. **`vendor/hcs` is a gitlink mirror, and it is now in sync.** HCS's regular files plus
   24 gitlinks. `scripts/vendor-sync.sh --apply` did it: 15 files copied, 1 gitlink
   recorded, 333 artifacts skipped, nothing deleted. Two things had to be true first —
   HCS's brunsli glue had to pass the 4-argument flag its own library defines (HCS#17),
   and a new gitlink has to be registered in the **superproject's** `.gitmodules`, not
   the vault's, or every recursive checkout dies with "No url found". Both are in the
   scripts now; `vendor-check` is green.
3. **The three media chains run now — and they lose.** They name `bin/srep.exe`, which
   cannot be shipped; `optional = true` drops such a step with a notice (heavenzip#92), and
   `precomp`'s exit 2 is accepted via `ok_exit = 0,2` (#94). Measured: they are worse than
   `plain` on every file tried, by 30% on a PDF, and byte-for-byte identical to `media`.
   Do not give the media route a chain of its own on this evidence. The one real trade is
   time: on a 93 KB PNG, `plain` is 7.3% smaller and 16× slower.
4. **The verify pass had a hole, now closed.** For a chain whose middle step writes to
   stdout, the reverse wrote nowhere and the next step read a stale intermediate, so
   "verified" was printed for an archive that does not decode. The manifest now records
   each step's `produced` path.
5. **The ratio ceiling is measured and the top of it is unreachable.** `paq8px -5` costs
   **1.2 KB/s** for −17.9% against the engine; it is GPL-2+ and can never be linked in.
   `zpaq -m5` is the reachable ceiling: −5.1% for 3.4×. `FINDINGS.md` §6h.
6. **A release asset is the one thing nobody rebuilds.** v1.4.2 shipped Linux only
   because the Windows job landed five days after the tag, and the artifact from the
   later `workflow_dispatch` run was built from `main`, nine commits past the tag. Do not
   attach a binary to a release it was not built from; cut a tag.

7. **The PNG transform now chooses what the model sees.** Per-row deltas (what the file stores,
   what deflate wants) or true pixels (what a context-mixing model wants). Measured: −26.3% on a
   screenshot, +49.7% on a photograph, so it is a 64 KiB trial over the *pixel stream*, never a
   constant. `FINDINGS.md` §6i. The trial's sample must come from the region that differs — 64 KiB
   of the whole payload chose wrong, 256 KiB of it chose right, 64 KiB of the pixel stream is
   cheaper than either.

## Traps that cost real time here

- **A new gitlink needs two .gitmodules.** The vault's own file is not the one git
  reads; the superproject's is, with paths relative to this repo. CI found this in eight
  seconds with `No url found for submodule path 'vendor/hcs/old/freearc-067'`.

- **`find` lies about a gitlink directory.** An uninitialised submodule can hold a stray
  clone; `find` counts it, git does not. Two of my measurements — "submodules are
  materialised", "247 mirror-only files" — were artefacts of exactly that. Use
  `git ls-tree`.
- **A `--dry-run` that returns before the notices** shows a plan that silently lost a
  step. Notices are printed before the dry-run return.
- **`precomp` writes to `-oFILE` and exits 2** when it has nothing to recompress. Both
  facts are load-bearing for the chains that use it.
- **A ratio cap on a deflate stream is decoration.** Deflate tops out near 1032:1, so
  the 4096× cap the other wraps use can never fire on a PNG. Cap by absolute size when
  the cost *is* the size — `kPngMaxInflated`.
- **A shallow clone cannot push.** `--depth 1` plus a 126 MB vendor pack makes every
  `git push` die with "unexpected disconnect"; the branch had to be built through the
  API. Clone full when you intend to push.
- **`--parallel` does nothing for a PNG.** The inflated payload is one block, so the work
  is single-threaded however many cores are offered; splitting it to enable threads costs
  10.8% (74,478 against 67,217 bytes) for 20% time.
- The rest of `docs/TRAPS.md` in heavenzip still applies.
