## Where the work actually is

**heavenzip** ships ten binaries and seventeen profiles. The bundle is
`heavenzip-1.0.0-linux-x86_64.tar.gz` (66 MB, with sources for every GPL/LGPL/Apache
tool) and `heavenzip-1.0.0-windows-x86_64.tar.gz`. Everything in `bin/` is built from the
vault by CI, not vendored:

| binary | builder |
|---|---|
| `ziptastic` | fetched from its release |
| `paq8px`, `srep`, `brotli`, `xz`, `precomp` | CMake or make-less build in `build-tools.yml` |
| `7z` | `tools/build-7z.py` — reads 7-Zip's makefile because the container has no make |
| `arc`, `unarc` | `tools/build-freearc.py` — same technique on `freearc-c-main` |
| `7z-wrap`, `arc-wrap`, `zpaq-wrap` | adapters giving archivers a one-file-in-one-file-out shape |

**FreeArc's configuration is captured, not guessed.** `config/freearc/` holds the real
`arc.ini`, the 284-entry method table, the 13 content groups, `fa.ini`, and the author's
own benchmark baseline. Read `docs/FREARC.md` first; it records what transferred, what did
not, and why.

## The five things a new session must know

1. **The engine wins and it is not close.** Silesia, 2 MB samples: 17–23% smaller than
   `xz -9` on three of four files, 2–4× slower. Any claim that a chain beats it needs a
   measurement from `tools/sweep.py`, and none has yet.
2. **The WAV segfault is real and unfixed** (ziptastic#22). `ziptastic -9 any-valid.wav`
   dies with SIGSEGV. A truncated WAV passes, which is how it hid.
3. **Never merge without reading the CI steps.** I broke this rule this session and put
   main red for one commit. A green conclusion is not the same as the new step having run.
4. **FreeArcCodecs.dll may not be redistributed.** FreeArc is free to use; that one file
   is reserved by the author, and it is the file that contains srep, lolz, precomp and
   every other external codec. We ship our own builds of srep and precomp from their own
   sources instead.
5. **`tools/check-pipes.sh` exists because prose did not work.** Piping into `head` under
   `pipefail` cost three CI cycles in one day, two of them after it was documented. When a
   trap is hit twice, write the gate.

```sh
# measure instead of arguing

```

## Traps that cost real time here

`docs/TRAPS.md` in heavenzip has twelve. The ones that bit this session:

- the sandbox loses `cmake` and `ziglang` on restart — reinstall before diagnosing a build
- `/tmp` is 64 MB; heavenzip writes its work directory beside the input for that reason
- zig must always be given `-target x86_64-linux-gnu.2.28`, or the binary's glibc floor and
  CPU baseline come from the host
- `find … | head -1` under `pipefail` exits 141 *after* doing its work
- a tool that writes to stdout needs `stdout_to_output = true`, not an output argument
- an archiver that appends an extension (`arc` → `.arc`) needs its adapter to rename
