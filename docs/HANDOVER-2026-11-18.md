- Report in tables and bullets, no paragraphs.
- **Re-verify the numbers in every reply** and keep pushing on speed.

## 6. Traps this session produced (do not relearn these)

1. **One fixture is not a class.** Five separate wrong measurements came from files the author chose.
   The answer is the holdout set, not discipline.
2. **`bench` with no flags measures WITHOUT precompression** — 86,626 where `-9` gives 51,822 on a
   PNG. `docs/PARETO.md` states it; `--help` still does not (that edit was reverted rather than
   shipped unbuilt).
3. **"Core dependencies are light" is a claim about a `pyproject.toml`, not about `pip install`** —
   docling's metapackage pulls **6.4 GB** and will not start in 2 GB RAM.
4. **A test CI never runs reads as coverage without being any** — heavenzip has no pytest step, so
   the similarity tests live in `--selftest` and a CI step runs them.
5. **A negative result names a design, not a format.** "LZ4 precompression does not pay" was true of
   storing the parse and false of re-encoding and comparing.
6. **Verify the neighbourhood of a change, not just the change.** Three bugs this session were in
   the lines *around* the edit (byte 5 vs 6; 23 vs 21 handlers; a removed import used 40 lines down).
7. **A hash in release notes is a statement about an artifact, not a reproducibility claim** —
   rebuilding the same commit produced different bytes.
8. **A sandbox limit that can be raised is not a limit.** `ulimit -v` reports 1,536,000 KiB, so
   `vite build` dies with `Cannot allocate Wasm memory for new instance` and the obvious
   conclusion is "the build cannot run here". The hard limit is **unlimited**:
   `ulimit -v unlimited` and it builds in 3.76 s. Two PRs shipped a comment saying the build was
   impossible before anyone tried the one command that fixes it.
9. **`git push` from this sandbox intermittently 502s**; the GitHub API path (blobs → tree → commit →
   ref) works. Tag creation needs `gh api --input -` with a JSON body.

failure: `pip install ninja cmake ziglang`, recreate `/scratch/work/tc/gcc` and `/scratch/work/tc/g++`
wrappers pointing at `zig cc`/`zig c++`, and set `ZIG_GLOBAL_CACHE_DIR`, `ZIG_LOCAL_CACHE_DIR`,

`/scratch/work`.
