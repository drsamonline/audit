# lz4 stops saying `copy` — the vault row is a real pin

Date: 2026-11-19 · Repos `drsamonline/HCS`, `drsamonline/ziptastic`, `audit` · HCS #20, ziptastic #69

The last loose end from the liblz4 bump: `vendor/hcs/SOURCES` recorded lz4 as `copy`, because the
tree stated 1.10.1 and upstream had no tag of that name — the vault said so itself. After the bump
to 1.11.1, that reason expired.

## Why this was worth doing rather than noting

A `copy` pin is an admission: "we cannot say which commit this is". It is honest, but it is a hole
in the vault's central claim — that every vendored source has a recorded upstream. The hole existed
only because upstream had not tagged the version the tree carried; tagging 1.11.1 closed it for
free, and the bump that made it possible was already done for other reasons.

That is the pattern worth keeping: **a `copy` row is a TODO with a date on it.** When the upstream
tags the version you already have, converting the row costs one commit.
